# Life RPG

Личная RPG-игра для прокачки себя в реальной жизни: квесты → опыт → уровни, характеристики, золото, магазин наград, ачивки.

- Игра: https://kirtokin.github.io/life-rpg/
- Стек: HTML/CSS/JS без сборки, Supabase (PostgreSQL + Auth), GitHub Pages
- Настройка игры (статы, квесты, награды, ачивки, баланс): `config.js`
- Авторы иконок и библиотеки: `CREDITS.md`
